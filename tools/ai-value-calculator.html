How it's calculated: Value = seats × habitual % × minutes saved ÷ 60 × working days × hourly cost × redeployment %. Return = value ÷ annual license cost. Activated-but-not-habitual users are counted as creating no measurable value. That's deliberately conservative, because one login a month doesn't change how work gets done.
